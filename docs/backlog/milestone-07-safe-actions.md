# Milestone 07 — Safe actions and Trash

## Goal

Implement selected item movement to Trash with confirmation and revalidation.

## Scope

- confirmation modal;
- metadata revalidation;
- duplicate keep-one enforcement;
- protected path checks;
- cache allowlist checks;
- move to Trash;
- local audit log.

## Acceptance criteria

- Permanent deletion is not implemented.
- Confirmation is required.
- Changed metadata blocks action.
- Selecting all duplicates in a group is blocked.
- Protected paths are blocked.
- Audit log records action results.
