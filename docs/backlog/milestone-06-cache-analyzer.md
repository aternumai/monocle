# Milestone 06 — Cache analyzer

## Goal

Analyze allowlisted cache folders and produce cleanup recommendations.

## Scope

- cache catalog;
- recursive size estimation;
- safety levels;
- recommendation command;
- frontend cache cards.

## Acceptance criteria

- Only allowlisted categories are actionable.
- `danger` categories are informational only.
- Each recommendation has reason and safety level.
- Permission errors are shown.
- No automatic cleanup exists.
