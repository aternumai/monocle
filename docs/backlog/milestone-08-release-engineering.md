# Milestone 08 — Release engineering

## Goal

Prepare public alpha release outside the Mac App Store.

## Scope

- release checklist;
- GitHub Release notes template;
- signing/notarization docs;
- checksum process;
- clean macOS test plan;
- update README with install instructions.

## Acceptance criteria

- Signed/notarized DMG process documented or automated.
- Release notes include limitations.
- Safety notes are visible.
- GitHub Release includes checksum.
- No secrets committed.
