# Milestone 01 — App shell and UX skeleton

## Goal

Create the first navigable UI without real scanner functionality.

## Screens

- Dashboard
- Scan setup
- Large files
- Duplicates
- Cache analyzer
- Settings

## Requirements

- Sidebar or top navigation.
- Empty states for each feature.
- Safety-first copy.
- No fake results except clearly marked mock/demo data in development.

## Acceptance criteria

- All MVP screens exist.
- UI clearly says no cleanup happens automatically.
- Scan button can call a placeholder command or disabled state.
- No unrestricted frontend filesystem plugin use.
