# Milestone 04 — Top 100 large files

## Goal

Show the top 100 largest files found during a scan.

## Scope

- backend top-100 ranking;
- query command;
- frontend table;
- sorting display descending;
- reveal in Finder action.

## Acceptance criteria

- Results are sorted largest to smallest.
- Uses allocated size when available, fallback to logical size.
- Table shows full path.
- Reveal in Finder works or shows clear error.
- No cleanup action required yet.
