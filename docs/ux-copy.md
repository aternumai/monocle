# UX copy bank

## Product positioning

```text
See what is taking space. Clean only what you choose.
```

```text
Monocle helps you inspect large files, exact duplicates, and cache folders on your Mac.
```

## Safety statements

```text
Monocle never deletes files automatically.
```

```text
Cleanup actions move files to the Trash. They are not permanently deleted by Monocle.
```

```text
Review the full paths before continuing.
```

## Permission copy

```text
Some folders could not be read because macOS blocked access.
```

```text
You can keep using Monocle with selected folders. Some protected locations may require Full Disk Access in a future broader scan mode.
```

## Cache copy

```text
This cache is usually safe to clear when the related app is closed. The app may recreate it later.
```

```text
Monocle shows this folder for visibility only and will not clean it in the MVP.
```

## Avoid

Do not use:

- “junk detected”;
- “your Mac is at risk”;
- “boost performance instantly”;
- “clean everything”;
- “delete forever”.
