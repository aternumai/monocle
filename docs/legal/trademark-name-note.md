# Name and trademark note

“Monocle” is a working product name.

Before public launch or commercial distribution, perform a dedicated clearance process:

1. search GitHub repositories;
2. search app stores;
3. search domains;
4. search package registries if publishing packages;
5. search trademark databases;
6. consult counsel for serious commercial use.

This document is not legal advice. It is a project reminder to avoid shipping under an uncleared name.
