# Maintainer checklist

## Before making repository public

- [ ] Confirm project name.
- [ ] Confirm license.
- [ ] Replace `OWNER/REPO` placeholders in GitHub templates.
- [ ] Add maintainer GitHub handles to CODEOWNERS.
- [ ] Review SECURITY.md contact process.
- [ ] Create initial labels.
- [ ] Protect `main` branch.
- [ ] Add a project board or issue milestones.

## After first code scaffold

- [ ] Add CI.
- [ ] Add dependency license check.
- [ ] Add formatting checks.
- [ ] Add Rust tests.
- [ ] Add frontend tests.
- [ ] Add screenshot to README.

## Before first binary release

- [ ] Apple Developer credentials ready.
- [ ] Signing/notarization tested.
- [ ] Clean macOS install tested.
- [ ] Security review completed.
- [ ] Release notes include safety limitations.
