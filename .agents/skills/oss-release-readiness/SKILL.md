# OSS release readiness skill

## Required reading

- `docs/11-open-source-github.md`
- `docs/14-release-checklist.md`
- `SECURITY.md`
- `CONTRIBUTING.md`
- `GOVERNANCE.md`

## Review checklist

- license present;
- README current;
- contribution guide current;
- security policy current;
- issue templates present;
- PR template present;
- release notes include limitations;
- no secrets committed;
- safety notes visible;
- signing/notarization steps documented for macOS release.

## Output

Produce a readiness report with:

- ready items;
- blockers;
- recommended fixes;
- release note draft.
